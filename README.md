# 原琴 MIDI 双路桥 · 移动端

[![Build Android APK](https://github.com/WayWarrior/genshin-midi-bridge-mobile/actions/workflows/android.yml/badge.svg)](https://github.com/WayWarrior/genshin-midi-bridge-mobile/actions/workflows/android.yml)

[![Platform](https://img.shields.io/badge/platform-Android%208.0%2B%20%7C%20HarmonyOS%204.x-3ddc84.svg)](#兼容性)

> Genshin MIDI Bridge (Mobile) — 把 USB MIDI 键盘 / 电钢琴接到**手机、平板**上，实时映射成《原神》21 键「风物之诗琴」的触控按键；同时支持导入 MIDI 文件自动演奏。

**这是移动端工程（Android APK / 鸿蒙安卓兼容环境），不是电脑端方案。** 网上同类工程大多跑在 PC 上（模拟键盘、模拟点击），本项目直接跑在手机或平板本地，不经过电脑转发，因此没有「电脑中转」那一层延迟。

非官方工具，与米哈游 / 原神官方无关。已开源，源码可自行审查。

## 它做了什么

- **双路输出**：同一份 MIDI 音符同时送给「内置本地音源」和「原神琴键触控」，本地采样先响、游戏声音后响，两路时间线来自同一个映射后的毫秒时钟。
- **21 键映射**：对应原神琴的 3×7 键位，内置 21 个 48 kHz 单声道 WAV 采样（C3–B5），不需要你逐个导入音色。
- **三点校准**：进琴界面后点悬浮球，按 C3 → B3 → C5 定位，自动推导整张琴的格子；也提供快速 3 点与 5 点核对。
- **按住保持**：实时键盘默认「按下保持触控、松开释放」，支持和弦与长音；另有 24 ms 短点按的兼容模式。
- **MIDI 文件自动演奏**：导入 `.mid` / `.midi`，选音轨、调外音处理、八度折回、BPM 覆盖、按原调转 C 调，然后点「开始演奏」，3 秒倒计时后自动弹。
- **游戏静音 / 开声**：原神没有对外音量接口，这套方案用「你录制的屏幕操作」重放：录一次「派蒙 → 设置 → 声音 → 拖滑条 → 返回 → 琴」，之后一键静音或一键开声。
- **悬浮球**：36 dp 小球，可拖动、记忆位置，点开是功能菜单。

## 工作原理（一句话版）

USB MIDI 事件 → 后台音源（AudioTrack 低延迟 PCM16）→ 本地发声；同一事件 → 触控计划器 → 无障碍 `GestureDescription` 注入原神琴键坐标。所以「本地听得见、游戏里在点」。没有网络权限，不读界面文本。

## 安装

1. 到 [Releases](../../releases) 下载 `GenshinMidiBridge_Harmony4_v0.18.apk`。
2. **先停止旧版音源，再直接覆盖安装，不要先卸载旧版**（0.18 与 0.2–0.17 的包名、无障碍组件、签名一致）。
3. 打开应用 → 「04 · 设置」→ 确认无障碍已开启。普通应用不能自己授予无障碍权限，必须手动开。
4. 打开「03 · 调音与声音」→ 点「检测并启用触点复用（约 3 秒）」，检测期间不要碰屏幕、不用连键盘。通过后会自动开启「按下保持触控」和「长按时复用触点」。

鸿蒙重置无障碍状态后仍需手动重开。

## 快速上手（对应演示视频）

> 演示视频：<https://www.bilibili.com/video/BV1HfH76GEeU/>

1. **开无障碍**：进系统设置 → 无障碍 → 找到本应用打开。担心风险可以只信源码，功能就在这几个 Java 文件里。
2. **连键盘**：应用首页「01 · 连接小琴」→ 刷新 → 选中 USB 设备（平板只有 Type-C 就插个 OTG 转接头）→ 启动，右下角测试键能发声就通了。这时响的是内置本地音源。
3. **绑游戏**：点「诊断/绑定」，把前台包名绑成你装的原神（B 服、官服都行）。
4. **校准**：进原神琴界面 → 点悬浮球 → 选「稳健 3 点」→ 依次点 C3 中心、B3 中心、C5 中心 → 21 个绿圈对齐后保存。
5. **开映射**：悬浮球菜单点「开启映射」，这时按琴键游戏里就会跟着响了。
6. **消掉双声**：默认本地采样和游戏声音会先后响，游戏那路延迟更大，会听出「两个声音」。做法是录一套「游戏静音」：悬浮球 → 声音设置 → 游戏静音 → 全部重新录制 → 按 派蒙 / 设置 / 声音 / 拖滑条 / 关闭 / 返回（/ 点琴）走一遍 → 保存。之后点「游戏静音」就会重放这套操作。
7. **弹**：开映射后就是低延迟的本地声音了，游戏静音状态下不会打架；多键和弦可用。
8. **（可选）MIDI 演奏**：在「02 · MIDI文件」导入 `.mid`，保存演奏设置、先本地试听；然后悬浮球里把「本地音源静音」、确认游戏声音是开的，点「MIDI文件」→「从头开始」→「开始演奏」，3 秒后自动开始。

### 换成自己熟悉的调

原琴是 C 调，比如《我不曾忘记》是 A 调、差一个小三度。想让手指用熟悉的 A 调指法去弹，就把调**往反方向平移一个小三度**（视频里定成降 E 调）——在「02 · MIDI文件」里用「按 MIDI 原调自动转为 C 调」+「共同移调」两处配合完成，别重复转两次。

## 构建

需要 JDK 17 + Android SDK 35（Gradle 8.9 wrapper 已在仓库里）：

```bash
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

Windows 用 `gradlew.bat`。仓库还带两条离线路线：

- `scripts/build-manual.sh`：不依赖 Gradle 的 ECJ/javac + aapt2 + D8 + apksigner 构建流程。
- `scripts/check-core.sh`：纯 Java 回归 + 内置 WAV 校验。

CI：`.github/workflows/android.yml` 会在 push / 手动触发时跑单测并产出 debug APK（Artifacts）。

## 已知限制

- **鸿蒙 5.0 及以上未测试**，鸿蒙 4.x 验证过；其他设备不保证。
- 延迟「和自己手指直接点平板差不多」，不是零延迟；过快的曲子仍会受影响，游戏帧处理和系统回调都可能让触控慢于本地声音。
- 实时长按最多同时保持 **10 个** 不同琴键，超出的输入会被忽略（本地音源不受影响）。
- 游戏静音 / 开声靠录制的屏幕操作重放，**屏幕尺寸或界面布局变了要重录**，且不能验证游戏实际音量。
- 文件触控只提供「琴类短点按」（每次约 24 ms），按音符时值长按的路径因游戏崩溃反馈已停用。
- 应用没有网络权限；不读取、不保存界面文本，前台检测只取包名/窗口状态。
